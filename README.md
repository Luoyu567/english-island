# 英语奇趣岛 H5 小游戏

## 项目档次
高档完整版：含低档、中档、高档全部功能。

## 运行方式
1. 电脑测试：双击 index.html，用浏览器打开。
2. 手机测试：把整个文件夹放到本地服务器，或上传到静态托管。
3. 微信内测试：部署到 HTTPS 静态托管后，生成二维码扫码打开。

## 功能
- 3-5岁：听音找图，2 个选项，无倒计时，可重播。
- 6-8岁：词图配对、首字母选择，进入题目自动朗读。
- 9-12岁：句子闯关，全部为句子题，每轮 10 题。
- 学习记录：最高分、错题、完成次数。
- 声音控制：重播、静音。
- 错题复习：首页入口。

## 数据
- 8 个主题：动物、水果、颜色、学校、食物、身体、天气、动作。
- 词汇约 400+。
- 句子 300 句。

## 文件说明
- index.html：入口页面
- css/style.css：样式
- js/data.js：词汇与句子数据
- js/audio.js：语音播放
- js/storage.js：本地存储
- js/game.js：游戏逻辑
